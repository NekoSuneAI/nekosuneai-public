#

# "Library cublas64_12.dll is not found or cannot be loaded".
#
# Versions are matched to ctranslate2 4.5+ (CUDA 12 + cuDNN 9). NekoSuneAI adds
# these packages' bin folders to the DLL search path automatically on Windows.
#
# Requires a recent NVIDIA driver. Works on Maxwell+ GPUs (e.g. GTX 980 Ti).
# If the GPU can't be used it falls back to CPU automatically.
